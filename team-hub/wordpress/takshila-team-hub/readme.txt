=== Takshila Team Hub ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0

The Takshila team dashboard inside WordPress.

== Installation ==
1. Plugins → Add New → Upload Plugin → choose takshila-team-hub.zip → Install → Activate.
2. A page called "Team Hub" (address /hub) is created, using the full-screen layout.
3. Settings → Team Hub: check the engine address (the Apps Script web app URL).

== Updating ==
Upload the new zip the same way and choose "Replace current with uploaded".
