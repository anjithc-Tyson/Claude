The funnel that matters most

From a first idea in the Design Studio to an approved CAD. Each step is one event; together they show where people drop out and what they buy.

  1. Opened studiostudio_opened
  2. Described the piecedesign_prompt_submitted
  3. Saw 3 directionsdesign_batch_generated
  4. Chose a directiondesign_direction_chosen
  5. Refined versionsdesign_version_created
  6. Finalized materialsdesign_finalize_started
  7. Boughtbuy_now_clicked
  8. Checkoutcheckout_started
  9. Paidorder_completed
  10. Approved CADcad_approved

Rules for developers

  • Names are snake_case, object_action in the past tense. Prices are numbers in major units (620, not 62000) with a separate currency.
  • Send order_completed, payment_failed and cad_approved from the server, so ad blockers and closed tabs can't lose revenue.
  • Keep one design_id from the first prompt through checkout and order, so studio activity joins to revenue.
  • Call setUserId() on sign-up and login and reset() on logout. Set is_internal on every staff and test account.
  • Never send prompt text, emails, names, phone numbers or addresses as properties.
  • Send page_type and logged_in on every event.

How to build it

The events are generated as typed functions, one per event, from the same file as this page. A misspelled event name or a missing property fails to compile. The full guide with every code sample is analytics/IMPLEMENTATION.md in the repo.

  1. Get the API keys

    Amplitude → Settings → Projects → default (814554) for production. Create a second Takshila (dev) project for local and staging builds, so test traffic never mixes with real data.

  2. Install the SDKs and copy the generated files

    Copy analytics/sdk/tracking.ts (browser) and analytics/sdk/server.ts (backend) into the codebase. Don't edit them by hand: regenerate with python3 analytics/build_tracking_sdk.py.

    npm install @amplitude/analytics-browser @amplitude/analytics-node

  3. Initialise once, and track every route change

    In the root layout. page_type and logged_in are then added to every event automatically.

    initAnalytics(process.env.NEXT_PUBLIC_AMPLITUDE_KEY, { debug: isDev });

// on every route change
setContext({ page_type: 'product' });
pageView({ page_path: location.pathname, page_title: document.title });

  4. Identify users on sign-up and login

    Use your own user id, never the email. This merges the visitor's anonymous history into their account.

    identifyUser(user.id, { user_role: 'buyer' });
signUp({ method: 'google', trigger_point: 'studio_save' });
// on logout
resetUser();

  5. Call one function where each action happens

    Fire it in the handler, after the action succeeds. Keep one design_id from the first prompt to the order.

    track.designPromptSubmitted({ design_id, prompt_length: prompt.length,
  has_reference_image: !!file, source: 'typed', location: 'studio' });
track.designDirectionChosen({ design_id, direction: 'signature', batch_number: 1 });
track.buyNowClicked({ context: 'studio_finalize', product_id: design_id,
  price: 2313, currency: 'USD' });

  6. Send revenue from the server

    order_completed, payment_failed and cad_approved live only in server.ts. Call them from the payment webhook and the CAD approval handler. The order id is used as the insert id, so a repeated webhook is counted once.

    await orderCompleted({ user_id, device_id }, {
  order_id: order.id, revenue: order.total, currency: 'USD' });
await setInternal({ user_id }, email.endsWith('@takshila.co'));

  7. Respect consent in the EU and UK

    Call amplitude.setOptOut(true) before initialising, and setOptOut(false) once the visitor accepts the cookie banner.

  8. Test with the dev project

    Run with debug: true, then open User Lookup in Amplitude and watch your test user's event stream live. Walk every P0 flow end to end. Anything Amplitude marks unexpected is a code mistake to fix.

  9. Launch

    Merge the new-site tracking-plan branch into main, mark the key events, stop sending the deprecated events below, and switch to the production key.
