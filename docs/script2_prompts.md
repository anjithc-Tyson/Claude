# Script 2 — "Live design studio" image prompts

All images are for the **preview window** of the design-studio panel, so they're **square (1:1)**, on a clean,
plain background, with the ring centred and filling about 60% of the frame. Nano Banana, 1:1.

**The same ring in every image.** Generate **P06 first**. Then generate P07–P12 with **P06 attached as the image
reference** and say "the exact same ring design, only change …". That keeps the band, setting and stone shape
identical, so the preview looks like one design changing.

Paste this style line at the end of every prompt:
`photorealistic product render, soft even studio light, plain warm cream background (#F4EEE4), subtle soft shadow, ring centred, sharp detail, no text, no logos, no hands unless asked, square 1:1`
