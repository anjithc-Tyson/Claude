## 1. The hero ring

Paste this block, word for word, into every prompt where it says **[RING]**:

> **[RING]** a delicate, fine-jewellery 18k yellow-gold ring: a slim 1.8 mm comfort-fit band with a soft, rounded high-polish profile; at the top an east-west set oval emerald (6 × 4 mm, about 0.5 ct), deep velvety green with natural soft inclusions, held low in a very thin polished gold bezel; two tiny round brilliant diamonds (1.5 mm) set flush into the band on each side of the emerald; inside the band, fine hand-engraved script "A · R 14.02.19" with crisp, slightly hand-cut letters; real 18k gold colour (warm buttery yellow, not orange, not brassy), realistic proportions for a woman's ring size 6 (inner diameter about 16.5 mm)

Rules for every image:
- **Make the master shot first (M00 below), then attach it as the reference image for every other shot.** Write "the same ring as the reference image" in each prompt.
- Ask for **9:16, the highest resolution available (2K or 4K)**.
- **Composition:** the ring (or the main subject) sits horizontally centred, about **38 % down from the top** of the frame. That's where her face is in the video, so the cuts match.
- If the tool takes a negative prompt, paste this **[NEGATIVE]** list:
  > CGI, 3D render, plastic, cartoon, oversaturated, orange gold, brass, chunky ring, thick band, oversized stone, two rings, stacked bands, warped band, melted metal, extra fingers, deformed hands, blurry engraving, misspelled engraving, glitter, sparkles, lens flare, glow, dark moody lighting, watermark, text artifacts

**[LOOK]: paste this wherever a prompt says [LOOK]:**
