**Video:** Script 4, "The finished piece is beautiful, but this is the detail that makes it personal".
**Edit:** detail-first hook + match cuts. The images replace D01–D13 one for one, so **keep the file names D01.jpg … D13.jpg** and the edit timings stay the same.
**Hero ring:** the Botanical Vine ring with the teal sapphire (reference image: `docs/script4_M00_reference_vine_teal.png`).

---

## 0. How to use this file

1. **Generate M00 (the master) first.** Regenerate until the ring is perfect, then attach it as the reference / "character" / "product" image for every other shot.
2. Every prompt below is **complete and self-contained**: copy the whole block into the prompt box. The ring, look, set and negative wording are already written into each one, so nothing needs assembling.
3. Settings for every image:
   - aspect ratio **9:16 (portrait)**
   - **highest resolution** the tool offers (2K or 4K)
   - photoreal / "photo" style, not illustration
   - if there's a "strength / similarity to reference" slider, set it high (about 0.8) so the ring stays identical
4. **Composition rule (why it matters):** in the video her face sits horizontally centred, about **38% down from the top** of the frame. Every product shot puts its subject in that same spot, so each cut from her face to the product lands in the same place (a match cut). The prompts say this in pixel terms: for a 1080×1920 frame, 38% ≈ 730 px from the top.
5. **Keep the top 12% and bottom 25% of every frame calm** (plain fabric, soft blur), so the labels at the top and the captions at the bottom stay readable.
6. Check every image against the checklist in section 5 before uploading.

## 2. The shared look (already written into each prompt)

- **Camera:** real full-frame camera; 100 mm macro lens for product shots, 85 mm for hand shots; f/4 (f/2.8 for the macro hook); ISO 100; tripod-sharp.
- **Light:** large soft north-facing window from camera-left (key light), 5200 K daylight, a white bounce card on camera-right lifting the shadows by about one stop, a faint warm rim from behind. Soft, wraparound, no hard shadows, no flash.
- **Reflections:** realistic reflections of the window shape in the polished rose gold; real sparkle in the diamonds (white fire, small rainbow flecks), real colour depth in the sapphire. No added glints, no lens flare, no glow.
- **Set and palette:** blush-pink linen (approx. hex #E9CFCB), warm cream (#F4ECE3), oat beige (#E6D8C6), dried baby's-breath and small pale blossom sprigs as soft background props. Everything softly out of focus except the subject.
- **Grade:** natural, slightly warm, true to life, gentle contrast, lifted soft blacks, creamy highlights. It should look like a luxury jewellery campaign photographed in daylight.
- **Hands (where present):** a woman's hands with **natural deep-brown skin** (approx. hex #6B4430 mid-tone, #8A5A40 highlights), real skin texture (fine lines, knuckle creases, pores), short neat oval nails in a soft nude polish, relaxed elegant fingers, **five fingers per hand**, no rings other than the hero ring. Cream chunky-knit sweater sleeve.

**Negative prompt (paste into the negative box if your tool has one):**
> CGI, 3D render, illustration, painting, plastic, toy, costume jewellery, oversaturated, neon, orange gold, yellow gold, brass, copper-red, thick band, chunky ring, oversized stone, navy stone, turquoise stone, green emerald, pink stone, extra stones, more than three marquise diamonds, extra leaves, missing leaves, deformed claws, floating stones, two rings, stacked rings, warped metal, melted metal, extra fingers, missing fingers, fused fingers, deformed hands, long nails, blurry engraving, misspelled engraving, text, watermark, logo, glitter, sparkle overlay, star filter, lens flare, glow, haze, dark moody lighting, harsh flash, hard shadows, cluttered background
